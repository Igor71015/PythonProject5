# Анализатор транзакций

Приложение для анализа финансовых транзакций из Excel-файлов, генерации JSON-отчетов и веб-страниц, а также автоматического формирования Excel-аналитики.

## Как запустить

1. Установите зависимости: `pip install -r requirements.txt` (или используйте созданный Virtualenv).
2. Поместите выписку в `data/operations.xls`.
3. Запустите главный модуль: `python -m src.main`
